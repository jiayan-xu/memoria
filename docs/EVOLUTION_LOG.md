## 0. 起点：一个过强的网传命题

**命题**：「纯 MD 文档记忆效果和效率都最高」。

深度调研（5 路并行，25 条引用）结论：

| 命题拆解 | 判定 |
|----------|------|
| 纯 MD **效率**最高 | 部分成立（工程默认，缺封闭对照） |
| 纯 MD **效果**最高 | 条件成立（干净结构有效，格式无 magic） |
| 纯 MD 是最优 **记忆**载体 | **不成立**（主流是原子事实） |

**定位修正**：Markdown 是优秀的**文档层中间态**，不是记忆层唯一载体。

→ 契约定为三层：

```
文档层  memory_type=document   干净 MD / 保结构文本
事实层  原子事实 + parent_id   检索/演化主路径
保真层  原件 raw_ref            PDF/DOCX/XLSX 不进 content
```

## 3. PR #22 — 表格保真 · HyPE 门 · 准入 · A/B

### 3.1 表格行保真切块

**问题**：超长 sheet 段退回字符切会撕 TSV 行、丢表头。

**方案** `chunk_preserving_rows`：

- 表格行（含 `\t` 或 `|`）占比过半 → 按**行边界**累积
- 每块**重复表头**
- 不用字符步进，行永不半截

### 3.2 HyPE 干净度门

**问题**：表格行 / OCR 噪声 / 代码生成的「假设问句」污染 HyPE，且白付 chat 费。

**方案** `is_hyde_worthy`（确定性、无 LLM）：

| 拦截 | 条件 |
|------|------|
| too_short | len &lt; 10 |
| tabular | 制表符/管道过多 |
| low_text_ratio | 字母数字中文占比 &lt; 35% |
| ocr_noise | 替换符/私用区/控制符 &gt; 4% |
| code_like | `{ } ; = &lt; &gt;` 密集 |

跳过计 `skip`/`skip_ids`，**不进** `fail_ids`（确定性不可修复）。

### 3.3 格式准入成文

`docs/INGEST_ADMISSION.md`：三层契约 + 准入表 + 硬纪律（禁 LLM 洗抽取文本、原件不进 content 等）。

### 3.4 A/B 闭环（P2）

`eval/eval_chunk_ab.py`：离线 2-gram TF-IDF，镜像 document.rs 算法。

| strategy | R@1 | R@3 | R@5 | avg_chunks |
|----------|-----|-----|-----|------------|
| fixed-512 | 0.500 | 0.875 | 0.938 | 25.3 |
| fixed-3500 | 0.750 | 1.000 | 1.000 | 2.8 |
| **heading-aligned** | **0.875** | 0.938 | **1.000** | **13.3** |

**结论固化**：

1. 文档层默认 **heading-aligned**（R@1 相对 fixed-512 **+37.5pp**）
2. 不回退 fixed-512
3. 与文献一致：**保留结构 ≫ 具体边界算法**
4. fixed-3500 块太少，证据粒度与 HyPE 喂入不如标题块干净

## 4. 当前形态（演进收敛点）

```
ingest
  ├─ 解析一次落盘（禁 LLM 洗文本）
  ├─ format_excel_serial          ← 日期可读
  ├─ chunk_text_structured
  │    ├─ 标题边界优先 + 面包屑
  │    └─ chunk_preserving_rows   ← 表格行完整 + 表头重复
  ├─ write_chunk_memories         ← parent-child 不变
  └─ HyPE 离线补嵌
       └─ is_hyde_worthy 门控
```

**未收敛（后续）**：

- 稳健解析器分流（扫描件/复杂表仍缺口）
- 真实部门语料 + embed 余弦复验 A/B
- 表单/公式原生工具链

---

## 5. 演进原则（本轮沉淀）

1. **先证伪绝对化命题，再定契约**——避免「纯 MD 一把梭」。
2. **对照源码再改**——parent-child 已有，差点重复实现。
3. **P0 修失真，P1 保结构，P2 用数据说话**。
4. **增量增强**（面包屑接在 i/N 上），不推倒已验证路径。
5. **确定性 skip 与瞬时 fail 分流**——HyPE 门不进 fail_ids。
